# Provenance notice

CellModeller2 is a clean-slate successor inspired by CellModeller, created by Tim Rudge, PJ Steiner, Jim Haseloff, and contributors at the University of Cambridge.

The original CellModeller repository contains a BSD-style license notice. No legacy source code has been copied into this initial implementation. Any future change that carries forward substantial legacy code, kernels, or fixtures must retain the applicable upstream copyright notice and license conditions and record the source commit in the change and fixture manifests.

The license for new CellModeller2 code has not yet been selected by the project owner.
